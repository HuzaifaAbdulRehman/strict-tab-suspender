# Privacy policy

Strict Tab Discarder is private-first. It does not collect, transmit, sell, or share personal data.

All settings are stored locally in Chrome. The extension may retain only the latest aggregate sweep summary, such as an aggregate count and timestamp. It never stores URLs, titles, favicons, domains, tab IDs, browsing history, or per-tab activity.

It has no host permissions and does not access page content. It makes no network requests and uses no telemetry, analytics, remote code, content scripts, accounts, or advertising.

Chrome does not provide a reliable signal for all unsaved forms. The extension cannot detect unsaved forms; save important work before relying on automatic discarding.
