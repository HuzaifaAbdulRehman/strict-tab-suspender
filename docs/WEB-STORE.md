# Chrome Web Store draft scope

Strict Tab Discarder v0.2.0 is a private beta and is not published to the Chrome Web Store. This document records the publication work that remains outside the repository release process.

## Before any submission

These account-specific assets cannot exist in the repository yet and are not implementation tasks:

- Publisher identity and verified developer account.
- Store listing screenshots, small promo tile, and any required promotional images.
- Store-category selection, support contact, and publisher dashboard declarations.
- A freshly reviewed ZIP from `package/strict-tab-suspender-<version>.zip`, with its checksum, SBOM, and contents list verified.

The listing/disclosure must state required `alarms`/`storage`, optional `tabs`, Chrome's “Read your browsing history” warning, transient URL parking, percent-encoded placeholder visibility and non-encryption, extension-ID recovery risk, no history API, no extension-storage URL database, no host permissions, and no network transmission. Do not submit or publish as part of the private-beta process.
