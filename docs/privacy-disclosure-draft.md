# Web Store privacy disclosure draft

Strict Tab Discarder does not collect, share, sell, or transmit user data. Settings are stored locally. The only retained operational information is the latest aggregate sweep summary. URLs, titles, favicons, domains, tab IDs, browsing history, and per-tab activity are not collected or stored.

The extension uses no host permissions, network requests, telemetry, analytics, content scripts, remote code, accounts, or advertising.

## Future publishing requirement

Enter this disclosure in the Chrome Web Store publisher dashboard and answer the dashboard's then-current data-use questions accurately before submission. This account-specific action cannot be completed from the repository.
