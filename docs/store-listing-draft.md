# Store listing draft

## Name

Strict Tab Discarder

## Short description

Privately discard eligible inactive Chrome tabs to reduce memory pressure.

## Full description

Strict Tab Discarder is a Chrome 121+ Manifest V3 extension with a focused goal: discard eligible inactive tabs after a chosen interval. It starts enabled with a 15-minute threshold and offers 15, 30, 60, and 120-minute presets.

It protects active, pinned, audible, already-discarded, and not-auto-discardable tabs. It waits five minutes after startup and discards at most 10 eligible tabs serially in a sweep.

Your settings stay local. The extension has no host permissions, no network calls, no telemetry, no ads, and no accounts. It never stores URLs, titles, favicons, domains, tab IDs, or browsing history.

Important: Chrome cannot reliably expose all unsaved forms. Save important work before automatic discarding.
